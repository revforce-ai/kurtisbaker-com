# AIR® Organizational-Document Catalog

The master list the responder draws from. This doubles as the **recommended
full set of documents to make available** — the items vendors (onboarding /
payment setup) and grant applications (due diligence) most commonly request
from a 501(c)(3).

## How to use this file
1. Fill in every `<<FILL IN>>` once (numbers + Drive locations).
2. Keep one canonical, current copy of each document in the Drive folder below.
3. The skill matches a request to a row, checks the **Tier** before attaching,
   and links to the website where **On website? = Yes**.

**Drive source folder:** `<<FILL IN: e.g. "AIR — Org Documents" Drive folder link>>`
**Naming convention:** `AIR_<DocName>_<YYYY>.pdf` (e.g. `AIR_W9_2026.pdf`,
`AIR_Form990_2024.pdf`) so the skill can find the current version by year.

## Maintenance
- Refresh the **W-9** at the start of each calendar year (date it for the new year).
- Replace **Form 990** when the new return is filed.
- Refresh the **COI** when the policy renews; never send an expired certificate.
- Re-verify the **charity registration** is current at its renewal date.
